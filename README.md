# どうぶつえん掲示板

動物園テーマの、カラフルでポップな家族向け掲示板です。お名前と好きな動物スタンプを選んで、コルクボードにひとことを貼り出せます。

## 公開ページ

GitHub Pages: https://michukyr2.github.io/zoo-bulletin-board/

## 投稿の保存について

このページは単体のHTML/CSS/JavaScriptだけで動く静的サイトです。バックエンドサーバーを持たないため、投稿はブラウザの `localStorage` に保存されます。つまり、**投稿は入力した本人のブラウザの中だけに残り、他の人の端末には表示されません**（同じ端末・同じブラウザで開き直すと自分の投稿は残っています）。

家族や友だち全員で投稿をリアルタイムに共有したい場合は、Firebase等の外部データベースを組み込む改修が必要です。

## ローカルで開く

```bash
open index.html
```

またはローカルサーバーで:

```bash
python3 -m http.server 8000
```
